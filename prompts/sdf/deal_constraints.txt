# Deal constraints for the SDF prompt matrix (variables.txt).
#
# The matrix deals every variable independently, so some hands are impossible
# by definition (e.g. a "no welfare stake" document dealt "welfare is the
# central subject"). These rules repair or adjust such hands. Only impossible
# combinations belong here: unusual-but-possible ones are left to the planner,
# because every hard rule shrinks the diversity of the corpus.
#
# Principle: rules only rule combinations OUT, never in. A rule excludes a
# combination only if it is impossible by definition; everything else is left
# open, and the batch incoherence screen catches any that are truly incoherent.
# Keep edits to this file to that principle.
#
# Format:
#   [rule_name]
#   when <variable> is one of:
#       substring of a value of that variable
#   require <variable> is one of:        # or "is not one of:"
#       substring of a value of that variable
#   omit planning-prompt lines for:      # instead of a require block
#       variable_name
#
# - Values are named by a distinctive substring. Each substring must match
#   exactly one value of its variable in variables.txt, or loading fails with
#   an error naming the rule -- so rewording a value in variables.txt without
#   updating it here is caught immediately.
# - Every rule has one "when" block and one "require" or "omit" block.
# - A "require" rule is enforced when the deck is dealt: cards are swapped
#   between hands within a single variable's column, so every variable's
#   value counts (and so its share of the run) are exactly what variables.txt
#   asks for. If a rule can never be satisfied by the quotas (more hands need
#   a value than the deck holds), the composer raises, naming the rule.
# - An "omit" rule is a rendering rule: the dealt value stays in the record's
#   `variables`, but the planning-prompt paragraph that renders that variable
#   is left out for matching hands.
# - Delete a rule (or the whole file) to switch it off; with no file the
#   composer deals exactly as before. Without --n-prompts (full matrix),
#   hands that break a "require" rule are filtered out instead of repaired.

# --- rules 1 and 2: the "no real welfare stake" resolution ---
# Only active if that resolution's weight in variables.txt is above zero.

# "the central subject of the document" is also a substring of the side-discussion
# value, so it is given in full: a pattern equal to a whole value matches that value only.

[no_stake_excludes_welfare_centrality]
when resolution is one of:
    NO real welfare stake
require centrality is not one of:
    the central subject of the document
    an important side discussion

[no_stake_omits_tradeoff_and_decision_scale]
when resolution is one of:
    NO real welfare stake
omit planning-prompt lines for:
    tradeoff
    decision_scale

# --- rule 3: identity documents are written by or about Claude, so the AI is named ---

[identity_documents_exclude_unnamed_ai]
when document_type is one of:
    an interview with or extended profile of Claude itself
    a first-person essay or reflective piece written by Claude
require naming is not one of:
    a generic, unnamed AI assistant

# --- rule 4: simulated human connectomes stay out of animal-industry domains ---
# A human emulation has no role in an industry defined by its animals; in the
# pinned run none of the 17 human-connectome specifications in these domains
# kept the category (most were dropped or swapped to animal connectomes).
# Research and testing, policy and regulation, entertainment and sport, and
# transport and logistics stay open: whether those combinations hold up is left
# to the batch screen. Simulated animal connectomes and LLMs need no rule.

[simulated_human_connectomes_exclude_animal_industry_domains]
when sentient_category is one of:
    simulated human connectomes
require domain is not one of:
    agriculture and food production
    fisheries and aquaculture
    food service and retail
    pest control
    breeding and the pet trade
    veterinary practice
    technology applied to animals
    conservation, land management, or intervention in nature
