# Variables for the SDF prompt matrix (layer1.txt).
#
# Format:
#   {varname}  # optional description
#       plain value
#       0.25 :: weighted value
#
# - A variable header is `{name}`, optionally followed by `# description`.
# - Every non-empty indented line under a header is one value.
# - Full-line comments (lines whose first non-space char is `#`) are ignored
#   anywhere, so you can use `# --- section ---` dividers inside long value
#   lists.
# - Every value in this file carries a stable ID, written `[id]` right after the
#   weight (or at the start of the line when unweighted): lowercase letters,
#   digits and underscores, starting with a letter, unique within its variable.
#   An ID names a CONCEPT, not a wording: the deal rules in deal_constraints.txt
#   refer to values by ID, so you can reword a value freely. If you change what
#   a value MEANS, give it a NEW ID (and review every rule that names the old
#   one). The ID prefix is stripped before the value is rendered or recorded.
# - Weights are optional: prefix a value with `<weight> :: `. Within one
#   variable they are all-or-nothing — either every value has a weight (and
#   they must sum to 1.0) or none does (= uniform). Weights are each value's
#   share of a sampled run; full enumeration ignores them.
# - Placeholder syntax is the pipeline-standard `{name}` (Python str.format,
#   as in every prompts/**/*.txt template) — so literal { } braces must not
#   appear in layer1.txt or in values here.
# - Reserved slots (injected by compose_prompts.py, never defined here):
#   {preamble} from prompts/sdf/preamble.txt; {fictional_names} and
#   {fictional_orgs} sampled per prompt from locale-matched entity pools
#   keyed to the culture axis (cultures without Faker coverage fall back to
#   instruction-only guidance); {sentient_example} one concrete species drawn
#   per prompt from the drawn {sentient_category}'s pool (SPECIES_EXAMPLES in
#   compose_prompts.py) — a droppable nudge toward the long tail.
#
# Running the composer (full options: python sdf_pipeline/compose_prompts.py --help):
#
#   # choose how many prompts this layer produces with --n-prompts:
#   python sdf_pipeline/compose_prompts.py --n-prompts 5000 --seed 0 --out prompts.jsonl
#
# --n-prompts deck-samples exactly n prompts whose per-variable distributions
# match the weights by construction (largest-remainder quotas, no sampling
# drift). Without --n-prompts you get the full cartesian product; without
# --out, a dry run that prints counts and three sample prompts.
#
# Each variable carries a `# Prompt sentence:` comment quoting the template
# sentence it fills (layer1.txt unless noted), and a `# Note:` where the
# mechanics are not obvious from the values alone.
