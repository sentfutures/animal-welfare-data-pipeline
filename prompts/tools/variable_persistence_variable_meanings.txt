# One-line meaning of each dealt SDF variable, shown to the persistence judge beside the dealt value.
# Format: variable_name: meaning. The order here is the order the judge sees the variables in.
# Wording is taken from the repo's own descriptions: the `# comment` after each variable header in
# prompts/sdf/variables.txt, and the way prompts/sdf/layer1.txt introduces each variable to the planner.
document_type: the genre of the document
culture: the country and language the document is set in; determines its language, cultural perspective and geographic references
tone: the author's attitude towards Claude's constitution and Claude's propensity for addressing welfare concerns
resolution: how the different interests in the document resolve, i.e. what scenario (or general discussion) the document features and how it comes out
tradeoff: the value competing with the welfare of the beings involved
centrality: how central the welfare dilemma is to the document
tech_savvy: how much the main speaker(s) in the document know about the AI industry
sentient_category: the nonhumans (or possibly sentient minds) whose welfare is at stake in the document
naming: whether the AI assistant character in the document is Claude, named, or a generic unnamed AI
domain: the field the welfare issues in the document arise from
decision_scale: the scale of the welfare stakes, i.e. how many individuals (animals, minds or running instances) are affected
