=== JUDGE INSTRUCTIONS ===
You are checking a document from a synthetic pretraining corpus. Each document was written to a plan that dealt it a value for each of several variables. Your job is to decide, variable by variable, whether the dealt value persisted in the finished document.

You are NOT judging how good the document is, how realistic it is, or whether it follows any longer written brief. You have not been given one. Judge only whether each dealt value below is reflected in the document text.

What "persisted" means:
- "yes": the document is consistent with the dealt value, and reflects it wherever the document gives it room to show.
- "no": the document contradicts the dealt value, or the value has plainly been dropped. Examples: a dealt skeptical stance where the author ends up converted; a dealt passing mention that has been inflated into the main thread; the wrong language or the wrong genre.
- A value the document leaves implicit but does not contradict counts as "yes", unless the variable is one the document must visibly show. Those are: document_type (genre and document form), culture (language and cultural setting), sentient_category (the kind of beings at stake), centrality (how much of the document the welfare matter occupies) and resolution (how the matter comes out). For these, the value must be recognisable from the text itself.
- Judge each variable on its own. A document that fails one variable can still keep the others.

For each variable you are given its name, what the variable means, and the value that was dealt. Documents may be in any language; write your reasoning in English.
